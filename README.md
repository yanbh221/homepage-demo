
# 多公司银行年报 RAG 智能检索与分析系统

## 一、 系统架构与功能说明

* **核心栈**：`pdfplumber` (高精度 PDF 文本解析)、`scikit-learn` (TF-IDF 字符级向量与余弦相似度计算)、`rank_bm25` (BM25 关键词检索支路)、`Streamlit` (可视化交互界面)。
* **双路混合检索机制 (Hybrid Search)**：
* **支路一（TF-IDF 向量检索）**：捕捉深层语义相似性，应对同义替换与复杂表述。
* **支路二（BM25 关键词检索）**：基于词频统计，高精度锁定专有名词、核心财务指标及特定代码。


* **实体前置过滤优化**：针对多银行年报容易出现的交叉干扰，系统在 `app.py` 中实现了**目标银行实体前置过滤机制**，在特定银行查询时自动锁定对应公司的知识块，兼顾全局检索与精准对齐。
* **元数据层级管理**：文本切片（Chunking）完整保留了“公司名称、报告期（2026半年报）、章节标题、页码粒度（Page Level）”等多维元数据标签。
