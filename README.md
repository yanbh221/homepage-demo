# 多公司银行年报 RAG 智能检索与分析系统

## 一、 系统架构与功能说明
* **核心栈**：`pdfplumber` (文本解析)、`scikit-learn` (TF-IDF 字符级向量与余弦相似度)、`Streamlit` (可视化交互界面)。
* **检索优化**：针对多银行年报容易出现的交叉干扰，系统在 `app.py` 中实现了**目标银行实体前置过滤机制**，在特定银行查询时自动锁定对应公司的知识块，兼顾全局检索与精准对齐。
* **架构说明与后续演进**：当前版本采用 TF-IDF 文本相似度检索并精确至页码粒度（Page Level）。后续计划引入 BM25 检索支路构建双路召回，并接入目录树解析以补齐章节元数据（Chapter Level Metadata）。
